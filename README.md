# Lulu | Product Designer Portfolio

A static website: plain HTML and CSS, no build step and no dependencies.

## Pages
- `index.html` (home)
- `tikka.html`, `atelia.html`, `kudi.html`, `lets-pay.html`, `topboard.html`, `maze-runner.html` (case studies)
- `assets/img` (project images, WebP) and `assets/fonts` (Alte Haas Grotesk)

## Run it locally
Open `index.html` in a browser, or from this folder run `python3 -m http.server` and visit http://localhost:8000

## Deploy
1. Push this folder to a GitHub repository.
2. In Vercel, choose Add New > Project, import the repository, leave every setting at its default
   (Framework Preset: Other, no build command, no output directory), then Deploy.

## Notes
- The accent colour is `#623528`. Search and replace it to change it.
- Headings use Alte Haas Grotesk. Check the font's licence terms before publishing publicly.
- Body text uses Manrope, loaded from Google Fonts.
